# charter

1. **No mobile client:** I will only target a desktop web browser. I will build on my existing knowledge of web routing and HTML templates, and I will not spend this semester learning Swift or Kotlin.
2. **No new primary database engine:** I will use a single relational database I am already familiar with, such as Microsoft SQL Server. I will not try to learn and throw in a NoSQL database like MongoDB.
3. **No custom interaction design from scratch:** I will use a standard component library or CSS framework. I will not spend time building complex, layered wireframes in tools like Axure RP.
4. **No real-time communication features:** The application will rely on standard HTTP request/response cycles. I will not put in WebSockets, live chat, or real-time push notifications.
5. **Strict 15-hour weekly limit:** I will not borrow time from my personal life or my wedding planning. When the 15 project hours are up for the week, capstone work stops until Monday. The only exception is if I have to prepare for a future week where 15 hours is not feasible.
